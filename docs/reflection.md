## ภาคผนวก — เฉลยเชิงเทคนิค (สำหรับตรวจความเข้าใจ)

1. **เปิดไฟล์ตรง ๆ** เบราว์เซอร์อ่าน HTML จากดิสก์ผ่าน `file://` ไม่มี HTTP request
   ไม่มี Jinja แทนค่า `{{ }}` ไม่มี route `/calculate` และไม่มี Python รัน
   ตัวเลขจะว่างหรือแสดง placeholder เท่านั้น
2. **ฟอร์มส่งข้อมูล** ด้วย `POST /calculate` แบบ `application/x-www-form-urlencoded`
   Flask อ่านที่ `request.form`, แปลงเป็น float, เรียก `dc_bias.calculate()`
   แล้ว render `index.html` กลับเป็น HTML ใหม่
3. **ไม่ต้องแก้ HTML** เพราะ template แสดงผลจาก object `DcBiasResult` เท่านั้น
   สมการอยู่ใน `dc_bias.py` ที่เดียว — นี่คือประโยชน์ของการแยกชั้น
4. **Warning จำเป็น** เพราะ Forward-Active approximation ใช้ไม่ได้ใน Cutoff/Saturation
   (เช่น VCE ติดลบหรือ VTH ≤ VBE) ถ้าไม่เตือน ผู้ใช้จะเข้าใจว่าค่าที่เห็นคือผลจำลอง
   ที่เชื่อถือได้ ซึ่งนำไปใช้ตัดสินใจผิด
